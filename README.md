# Excel кабинет

Сайт для загрузки Excel-файла, выбора людей по фамилии, заполнения нужных колонок в строках выбранных людей и скачивания обновленной таблицы.

## Запуск

```bash
npm install
npm run dev
```

После запуска откройте `http://127.0.0.1:5173`.

## Доступ

- Логин: `admin`
- Пароль: `12345`

## Как пользоваться

1. Войдите на сайт.
2. Загрузите файл `.xlsx` или `.xls`.
3. Выберите лист и колонку, где находятся фамилии.
4. Отметьте нужных людей.
5. Укажите колонку Excel для заполнения, например `E`, и значение.
6. Нажмите `Скачать Excel`.
